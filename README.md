# 车祸大会Bingo

把开会时最爱发生的荒唐事做成宾果：会中听到一句就点一下，横排、竖列或斜线连成一条线，这场会当场判定"翻车"；散会补两句现场状况，自动生成一份毒舌事故报告。

## 它能做什么

- **单文件网页**：`assets/quiz.html`，离线双击即用，零外部依赖、不联网、不上传。
- **开场选择**：选会议长度（3×3 / 4×4 / 5×5 三种盘面），选模式（会前计时 / 会后才玩）。
- **会中勾格**：连成一线即弹出"翻车"横幅 + 音效 + 高亮，右栏四类损伤实时计数与本局命中进度条。
- **散会复盘**：多选现场状况、留一句吐槽，生成横排一屏的事故报告（主因 / 元凶 / 翻车指数 / 四等评级 / 毒舌评语），可一键保存 2480×1520 PNG，也可复制 URL hash 分享链接。
- **本地优先**：勾选只存本机 localStorage，刷新不丢，封存报告后即清；分享链接只带勾选结果与吐槽文本。

## 安装与使用

1. 把 `assets/quiz.html` 复制到任意目录，双击在浏览器打开即可。
2. 若要把本技能装入 WorkBuddy 本地技能库，将整个技能目录放入 `~/.workbuddy/skills/` 即可。
3. 想改题、改色、改四轴命名或导出，直接改 `assets/quiz.html` 源码即可。

## 设计要点

- 独立四维损伤模型（跑题 / 空转 / 加码 / 劝退）与独立计分模型（封顶 100，四等评级）。
- 横排海报按视口等比缩放，桌面零滚动；统一安全边距，顶栏、页脚、海报对齐同一条内容轴线。
- 盘面格子与全部选项为原生按钮（aria-pressed），键盘可玩，尊重系统减弱动效。

## 说明

这是一款**娱乐自评工具**，不是标准化心理量表，未做信效度检验，不做任何临床诊断。全部计算在本地浏览器完成，不联网、不上传。
